# Mob Morph (Fabric 1.20.1)

Сборка: открой папку в IntelliJ IDEA (импортируй как Gradle-проект) и выполни задачу `build`,
либо в терминале: `gradle wrapper --gradle-version 8.5` и затем `./gradlew build`.
Готовый .jar будет в `build/libs/mobmorph-1.0.0.jar`. Нужен Fabric Loader + Fabric API 0.92.2 для 1.20.1, Java 17.
Мод должен стоять у ВСЕХ игроков (и у тебя, и у друга).

Команды (нужны права оператора / читы):
  /morph <моб> [игроки]   — превратиться (или превратить друга!), напр. /morph minecraft:creeper
  /morph off [игроки]     — вернуться в обычный вид

Клавиши (меняются в настройках управления):
  R — способность моба
  G — Эндермен: взять / поставить блок, на который смотришь

## Сборка без установки чего-либо (GitHub)
1. Создай репозиторий на github.com, загрузи в него содержимое этой папки (кнопка Add file → Upload files; папку .github тоже).
2. Вкладка Actions → дождись зелёной галочки (3–5 минут).
3. Открой запуск → внизу Artifacts → скачай mobmorph-jar → внутри готовый mobmorph-1.0.0.jar.
